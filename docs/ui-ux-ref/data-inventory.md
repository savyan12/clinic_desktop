# جرد البيانات ومصفوفة التكافؤ

هذا الجرد مبني على شاشات Vue الحالية، استدعاءات `src/api` وتعريفات التقارير، وليس على الصور فقط. الحالة الابتدائية لكل حقل: **محفوظ**؛ يُحدّث مكانه الجديد عند نقل الشاشة.

## لوحة التحكم

| البيانات/العملية | المكان الحالي | المكان الجديد المخطط | الحالة |
|---|---|---|---|
| التحية، التاريخ، تسجيل جلسة | رأس الصفحة | رأس الصفحة | محفوظ |
| `stats` كاملة | شبكة KPI | 4 StatCards أساسية + ملخص إداري | محفوظ |
| جلسات اليوم: الوقت، المريض، الهاتف، الطبيب، الخدمات، التغطية، الحالة | جدول | ActivityFeed/قائمة غنية مع فتح التفاصيل والطباعة | محفوظ |
| فلاتر البحث والطبيب والحالة والتاريخ | card منفصلة | شريط خفيف داخل قسم الجلسات | محفوظ |
| الاشتراكات القريبة: المريض، الاسم، الخدمات، المتبقي | شريط cards | قسم تحتاج متابعة | محفوظ |
| المقبوضات، الديون، مستحقات الأطباء | ملخص مالي | بطاقة داكنة واحدة/قائمة أرقام | محفوظ |
| أحدث الحركات: النوع، المريض، المبلغ | قائمة | ActivityFeed | محفوظ |

## المرضى وملف المريض

| البيانات/العملية | المكان الحالي | المكان الجديد المخطط | الحالة |
|---|---|---|---|
| القائمة: الاسم، الهاتف، الجنس، المنطقة، حالة الاشتراك، الجهة | جدول | جدول: المريض/الهاتف، الجهة، الاشتراك، الدين، آخر زيارة؛ الجنس والمنطقة في الملف | محفوظ/ينقل |
| فلاتر البحث وحالة الاشتراك | card | FilterBar داخل card الجدول | محفوظ |
| إضافة مريض: الاسم، الهاتف، العمر، الجنس، المنطقة، هاتف الطوارئ، الجهة | Dialog | Drawer قصير/متوسط مع labels ظاهرة | محفوظ |
| بيانات الملف الأساسية + تاريخ الإنشاء | header + تبويب بيانات | Header غني + تبويب البيانات | محفوظ |
| الجلسات: التاريخ، الطبيب، الخدمات، القيمة، التغطية، الحالة | تبويب جدول | تبويب الجلسات | محفوظ |
| الاشتراكات: الاسم، الخدمات، المستخدم/المتبقي، القيمة، الحالة | cards | تبويب الاشتراكات + card الاشتراك الحالي | محفوظ |
| الرصيد، الدين، حركات الرصيد، الديون، المدفوعات والاسترجاعات | تبويب مالي | تبويب الحساب المالي | محفوظ |
| شحن رصيد، تسديد دين، دين افتتاحي، استرجاع، كشف حساب | أزرار/dialogs | نفس العمليات ضمن تبويب مالي واضح | محفوظ |

## الجلسات

- القائمة: التاريخ/الوقت، رقم/كود الجلسة، المريض والهاتف، الطبيب، الخدمات، القيمة، نوع/تغطية التسوية، الحالة، فتح/طباعة.
- الفلاتر: بحث، طبيب، حالة، تاريخ؛ موظف الاستقبال يرى جلسات اليوم وفق الصلاحية الحالية.
- إنشاء الجلسة: المريض، النوع (فردية/اشتراك)، الاشتراك عند الحاجة، الطبيب المشرف، التاريخ، الخدمات والملحقات، الخصم، الرصيد، المدفوع، طريقة الدفع، الجهة الراعية للدين، الملخص المالي.
- تفاصيل الجلسة: المريض، الطبيب، التاريخ، الخدمات والأسعار/الإضافات، الإجمالي والخصم والصافي، التسوية والمدفوع والدين، نصيب الطبيب للجلسة الفردية، الحالة، الطباعة، التعديل/الإلغاء/إضافة خدمات حسب الصلاحية والقواعد.

## الاشتراكات

- القائمة: المريض، اسم الاشتراك، الخدمات، الجلسات المستخدمة/الإجمالية/المتبقية، البداية، السعر، المحصل، المسترجع، المستحق، الحالة والإجراءات.
- الإنشاء: المريض، الاسم، الخدمات المغطاة، عدد الجلسات، السعر الإجمالي، المدفوع عند الإنشاء، طريقة الدفع.
- التفاصيل: بيانات المريض والبداية والحالة، التقدم، الخدمات، جلسات الاستخدام والطبيب المشرف، الدفعات، الدين، الإلغاء والاسترجاع، وتصحيح عدد الجلسات والسعر مع السبب.

## الأطباء والمستحقات

- القائمة: الاسم، الهاتف، النسبة، عدد الجلسات، المكتسب، المصروف، المتبقي، الحالة.
- إضافة/تعديل: الاسم، الهاتف، نسبة الاستحقاق، نشط.
- التفاصيل: بيانات الطبيب، النسبة والحالة، الجلسات المحتسبة بقيمتها ونسبتها ومستحقها، دفعات الطبيب، المجاميع.
- صرف مستحق: المبلغ، التاريخ، الطريقة، الملاحظة؛ لا يتجاوز المتبقي.

## الخدمات

- القائمة: الاسم، السعر الحالي، الوحدات المشمولة، اسم الوحدة، سعر الإضافة، الحالة.
- إضافة/تعديل: الاسم، السعر، الوحدات المشمولة، اسم الوحدة، سعر الوحدة الإضافية، نشط، سبب التعديل.

## الجهات الراعية

- القائمة: الاسم، الهاتف، العنوان، الحالة، المرضى/الدين حيث يوفرهما الرد.
- إضافة/تعديل: الاسم، الهاتف، العنوان، نشط.
- التفاصيل وكشف الحساب: المرضى، الديون، المدفوعات، الأصل/المسدد/المتبقي، وطباعة الكشف.

## المشتريات والإيجار

- النوع، الوصف، المستلم، الرقم المرجعي، تاريخ الدفع، طريقة الدفع، المبلغ، الحالة، ومبرر الإلغاء/التعديل إن وُجد.

## التقارير

| التقرير | الأعمدة والمجاميع المحفوظة |
|---|---|
| الجلسات | التاريخ، المريض، الطبيب، الخدمات، القيمة، الحالة؛ العدد وقيمة الخدمات |
| المقبوضات | التاريخ، النوع، المريض، الطريقة، المبلغ؛ المقبوضات والاسترجاعات والصافي |
| الديون | المرجع، المريض، المسؤول، الأصل، المسدد، المتبقي، الحالة؛ المجاميع الثلاثة |
| مستحقات الأطباء | الطبيب، الجلسات، المكتسب، المصروف، المتبقي؛ المجاميع |
| الاشتراكات | المريض، الاسم، البداية، المتبقي، الجلسات والطبيب المشرف، السعر، الحالة؛ العدد والحالات والجلسات والمبالغ |
| المشتريات والإيجار | التاريخ، النوع، الوصف، المستلم، المرجع، الطريقة، المبلغ، الحالة؛ العدد ومجاميع الأنواع |

الفلاتر المحفوظة: من/إلى، الطبيب، المريض، الجهة الراعية، الحالة، نوع المعاملة/المصروف/الدين، وطريقة الدفع. العمليات: طباعة، PDF، XLSX.

## المستخدمون والتدقيق والإعدادات

- المستخدمون: الاسم، اسم المستخدم، الدور، الإنشاء، الحالة، آخر دخول؛ إنشاء/تعديل/تعطيل/تفعيل/إعادة كلمة المرور.
- التدقيق: المستخدم، العملية، نوع السجل، التاريخ، الوقت، الكيان، البيانات السابقة والجديدة، وكون السجل للقراءة فقط.
- الإعدادات: أدوار حجم/وزن النص الأربعة، العملة، حجم الطباعة، إظهار الشعار، معاينة مباشرة، محركات USB، إنشاء نسخة احتياطية والتحقق منها.

## الطباعة والدخول والتفعيل

- الدخول: اسم المستخدم، كلمة المرور، إظهار/إخفاء، الخطأ، حالة التحميل.
- التفعيل: بيانات الترخيص والجهاز كما يعيدها Desktop bridge، مع حالات الجاهزية والخطأ.
- الطباعة: إيصال جلسة، كشف مريض، كشف جهة، وكل التقارير؛ كل القيم النصية والمالية الحالية محفوظة، مع نسخة أبيض وأسود لا تعتمد على اللون وحده.

## عمليات مالية مشتركة

- تسديد الدين: مبلغ، طريقة، توزيع/اختيار الديون حسب المنطق الحالي.
- شحن الرصيد: مبلغ، طريقة.
- الاسترجاع: الدفعة الأصلية، المتاح، المبلغ، الطريقة، السبب.
- الدين الافتتاحي: المبلغ، الجهة الاختيارية، الملاحظة.
- كل العمليات تستخدم idempotency الحالية وتحتفظ برسائل وأخطاء الـAPI كما هي.
