## الشاشات

### 01 — الداشبورد
- 6 KPI متشابهة كلها "د.ل 0" والصف الثاني غير متوازن، وسهم بلا وظيفة.
- لا يوجد hierarchy بين "جلسات اليوم" (يومي) و"إجمالي الديون" (إداري).
- **الهدف:** تحية + زر "تسجيل جلسة جديدة". صف من 4 StatCard (جلسات اليوم، المرضى الحاضرون، المقبوضات اليوم، قيمة الجلسات) بنسخة tinted. صف ثانٍ: شريط SnapshotCard لحالة الأطباء اليوم. بعده عمودين: (يمين) جلسات اليوم كـ ActivityFeed مع فلتر الطبيب، (يسار) "تحتاج متابعة": اشتراكات قريبة الانتهاء + ديون بـ list صغيرة. إجمالي الديون ومستحقات الأطباء غير المصروفة: بطاقة داكنة واحدة مقسومة لرقمين، أو StatCard قابلة للنقر.

### 02 — معالج تسجيل جلسة
- stepper صغير، وزر "التالي" نصي، وبحث المريض داخل حقل منفرد فيه فراغ كبير.
- **الهدف:** Modal أعرض (720) أو Drawer. Stepper بدوائر. الخطوة 1: بحث مريض كبير + نتائج كـ cards (اسم، هاتف، شارة اشتراك فعّال/دين) + "مريض جديد" كبطاقة بخط متقطع. الخطوة 3 (التسوية): ملخص محسوب في panel (الإجمالي، الخصم D-01، المدفوع، المتبقي).

### 03 — الجلسات
- فلاتر في card، وempty state عام.
- **الهدف:** card واحدة: tabs بالحالة مع عدادات + بحث + طبيب + تاريخ. جدول: (الوقت/التاريخ، المريض بـ avatar، الطبيب، الخدمات، المبلغ، الحالة chip، kebab). الحالة الفاضية `page` خاصة بالجلسات.

### 04 — المرضى
- إجراءان بنفس الشكل (إضافة مريض بزرين: header + empty).
- **الهدف:** جدول: (المريض + الهاتف، الجهة الراعية، الاشتراك الحالي chip + progress صغير، المتبقي/الدين، آخر زيارة). الصف كله clickable يفتح ملف المريض (الدفعة 2). فلتر حالة الاشتراك كـ tabs.

### 05 — الاشتراكات
- نفس بنية المرضى بدون إضافة قيمة.
- **الهدف:** جدول: (المريض، اسم الباقة، progress الجلسات `6/10`، المدفوع/المتبقي، الحالة chip). tabs: الكل / فعّال / قريب الانتهاء / منتهي.

### 06 — الأطباء ومستحقاتهم
- جدول سليم الفكرة، لكن 3 أعمدة "د.ل 0" متتالية بلا تمييز.
- **الهدف:** tabular-nums، عمود المتبقي بوزن أثقل (اللون الدلالي يُحدد مع الدفعة 2 حسب منطق الصرف)، النسبة chip صغير، avatar للطبيب، kebab فيه (تعديل، صرف مستحقات، تعطيل). فوق الجدول 3 StatCard (إجمالي المكتسب، المصروف، المتبقي).

### 07 — Modal إضافة طبيب
- ملاحظة معلوماتية خضراء ثقيلة، وزر الحفظ نصي.
- **الهدف:** AppField×3، تلميح طريقة حساب النسبة كـ helper رمادي تحت الحقل، toggle "نشط" بصف مستقل، الحفظ معبّى.

### 08 — Modal إضافة اشتراك
- نموذج طويل (9 عناصر) وملخص محسوب بلا حضور.
- **الهدف:** Drawer. أقسام: المريض، الباقة (اسم، خدمات، عدد الجلسات)، الدفع (السعر، المقدم، الطريقة). ملخص ثابت أسفل (قيمة، مدفوع، متبقي) بأرقام كبيرة، وتنبيه "كل زيارة مكتملة تخصم جلسة" كـ helper.

### 09 — Modal إضافة خدمة
- 3 حقول متجاورة في صف صغير (وحدات، اسم الوحدة، سعر الإضافي) تعطي حقولاً ضيقة وغير مقروءة.
- **الهدف:** قسم فرعي اختياري "ملحقات الخدمة" قابل للفتح، الحقول الثلاثة بعمودين بعرض مناسب أو 3 أعمدة بـ label فوق كل حقل.

### 10 — الجهات الراعية / 11 — Modal جهة راعية
- empty state مكرر، والـ modal بسيط.
- **الهدف:** جدول: (الجهة، الاتصال، المرضى المرتبطين، الدين المستحق، الحالة). الـ modal يبقى 3 حقول + toggle.

### 12 — التقارير
- 6 تبويبات بأيقونات، وأزرار Excel/PDF باهتة بينما "طباعة" هو الأساسي، وKPI من خلية واحدة.
- **الهدف:** تبويبات مبسطة (underline أو segmented). فلاتر في صف واحد مضغوط. StatCard للإجماليات. أزرار التصدير: "تصدير" dropdown (Excel, PDF) + طباعة كلاهما secondary. تذييل "أعد التقرير في..." صغير. مخطط (donut أو خط) حيث يفيد، والجدول تحته.

### 13 — المستخدمون
- empty state فقط.
- **الهدف:** جدول: (المستخدم avatar، الدور chip، آخر دخول، الحالة). إضافة مستخدم في drawer مع اختيار الدور.

### 14 — سجل التدقيق / 15 — تفاصيل العملية
- جدول سليم، والـ drawer قوي وظيفيًا، لكن كل القيم الجديدة في pills خضراء متشابهة.
- **الهدف:** سجل التدقيق كـ ActivityFeed مجمّع بالتاريخ (اليوم، أمس) مع الفلاتر فوقه. الـ drawer: جدول "قبل/بعد" (الحقل، القيمة السابقة بخط مشطوب خافت، القيمة الجديدة بـ success-bg فقط عندما تتغير)، وسطر القفل "السجل غير قابل للتعديل" كـ alert info.

### 16–17 — الإعدادات
- 4 cards كبيرة لضبط الخطوط، وتحذير USB بأيقونة غير مناسبة.
- **الهدف:** ما نحذف المعاينة الحية (ميزة ممتازة). نقسم الصفحة بتبويبات جانبية (العرض، الطباعة والعملة، النسخ الاحتياطي). كل دور خط في صف واحد: معاينة + select حجم + select وزن. التحذير `warning` بأيقونة مثلث. زر "إنشاء النسخة" معبّى.

4. معالج الجلسة والاشتراك.
5. التقارير والتدقيق والإعدادات.
