# دليل واجهة النظام — docs/ui-ux-ref

نظام إدارة عيادة عين الحياة للعلاج الطبيعي والتأهيل. واجهة عربية RTL، إدارية، تُستخدم يوميًا من موظف الاستقبال والمدير.

## تعليمات للـ AI (اقرأ قبل أي تعديل على الـ UI)

1. اقرأ بالترتيب: `01-direction.md` ثم `02-tokens.md` ثم `03-components.md`، وبعدها الملف الخاص بالشاشة اللي تشتغل عليها (`04-audit-batch1.md` أو `05-batch2-inner-screens.md`).
2. المراجع البصرية في `references/`. ماتنسخهاش حرفيًا. خذ المبادئ المذكورة في `references.md` فقط.
3. ممنوع تستعمل لون خارج `tokens.css`. ممنوع hex مكتوب مباشرة داخل المكونات.
4. اللون الأخضر للنجاح (success) فقط. لون الواجهة الأساسي هو `--accent`. أخضر الشعار يظهر في الشعار فقط.
5. الجدول يُستعمل فقط للبيانات اللي تحتاج جدول فعلاً (مقارنة أعمدة متعددة عبر صفوف كثيرة). غير هذا استعمل cards أو list أو feed.
6. حجم الخط ووزنه في 4 أدوار (النص العام، نص الجداول، عنوان القسم، عنوان الصفحة) يتحكم فيها المستخدم من صفحة الإعدادات. اربط الأدوار هذي بالمتغيرات `--fs-*` و `--fw-*` ولا تثبّت قيم px داخل المكونات.
7. كل شاشة تُختبر ببيانات حقيقية وبحالة فاضية وبحالة بيانات كثيرة (50 صف+) قبل ما نعتبرها منتهية.
8. قبل التسليم راجع قائمة "علامات الـ slop" في `01-direction.md` وقائمة الإنجاز في آخر هذا الملف.

## قائمة الإنجاز لأي شاشة

- [ ] عنوان الصفحة + إجراء رئيسي واحد فقط (filled). الباقي secondary/ghost.
- [ ] لا يوجد breadcrumb يكرر العنوان.
- [ ] الأرقام المالية بنمط: رقم كبير + د.ل صغير خافت + كسور أخف (إن وُجدت).
- [ ] حالات (status) بـ chip: خلفية فاتحة + نص غامق + نفس الألوان الدلالية في كل النظام.
- [ ] الحالة الفاضية: مخصصة للصفحة، صغيرة داخل الـ card، فيها إجراء واحد فقط.
- [ ] الحقول label فوق الحقل، مو floating.
- [ ] الزر الأساسي في أي modal/drawer معبّى وواضح.
- [ ] الجدول فيه tabular-nums للأرقام، وأقل من 8 أعمدة، وصفوف 52–60px.
- [ ] تباين النص ≥ 4.5:1 (المسموح للخافت الأدنى `--text-muted`).
- [ ] يشتغل تحت 1024px (الجداول تتحول لقوائم cards تحت 768px).
- [ ] مراجعة RTL: الأيقونات الاتجاهية (أسهم، next/prev) معكوسة صح.
