مهم:

- جهاز Windows مخصص للبناء والاختبار. جهاز Linux هو المصدر الأساسي للتطوير.
- لا تستبدل ملفات كاملة ولا تمسح تعديلات موجودة. افحص git status وgit diff أولاً، وادمج التغييرات مع الشغل الموجود.
